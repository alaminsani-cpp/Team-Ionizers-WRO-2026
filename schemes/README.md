# Schemes — interpretation

- `system_architecture.svg`: high-level proposed functional relationships, **not** a confirmed installed diagram.
- `power_topology.svg`: conditional power flow design (no real voltage/rail/pin data), **not** a buildable schematic.
- `state_machine.svg`: proposed logic, **not** the verified team's original source.
- `pinmap.csv`: **blank placeholder** to populate with actual electrical nets.
- `power_budget.csv`: empty measurement table.
- `BOM.csv`: empty verified bill of materials.

The physical robot must be documented with authentic electrical schematic, actual pin IDs, datasheet ratings and photos to satisfy WRO reproducibility.
