# WRO 2026 rule compliance audit

Read the official 2026 PDF and official Q&A for legally authoritative requirements. The following is an audit aid, not a replacement rule book.

## Public documentation
- [ ] Team's **public** GitHub repository link delivered to National Organizer on the communicated **14 November 2026** deadline.
- [ ] README in English with at least 5000 characters — **provided by this archive**.
- [ ] Engineering Journal PDF and Markdown version — **draft provided**, evidence still missing.
- [ ] Actual source code for **every programmed controller** — **MISSING from this archive**.
- [ ] Full photo set: vehicle front, back, left, right, top, bottom + team photo — **MISSING**.
- [ ] Two separate YouTube autonomous demonstrations (>=30 seconds each) — **MISSING**.
- [ ] Hardware diagrams: actual CAD/wiring/pin mapping — only conceptual diagrams provided; **actual drawings missing**.
- [ ] Authentic Git log: first commit >=20% of final code >=2 months prior; second >=1 month prior; third >=2 weeks prior — **UNVERIFIED**. Do not fake history.
- [ ] Repo remains public at least 12 months after the 2026 International Final.
- [ ] Print and take engineering-journal hard copy to the event.

## Physical robot and controller
- [ ] Vehicle fits 300 × 200 × 300 mm including mounted components.
- [ ] Total weight does not exceed 1.5 kg.
- [ ] Four wheels; one driving axle physically interconnected and a distinct steering actuator.
- [ ] No differential-drive wheelbase or independent left/right drive motors.
- [ ] No wireless communication enabled for the competition run.
- [ ] All onboard modules communicate over wires and run autonomously.
- [ ] Start procedure includes required power-on and start button behavior.
- [ ] Entire run is autonomous; nobody enters control data while running.

## Challenge scope
- [ ] Open Challenge: three laps, legal stopping, randomized direction/starting area.
- [ ] Obstacle Challenge: red -> right, green -> left, parking routine and legal final behavior.
- [ ] Optional surprise: modified 50/150 mm opposite-color sign passed according to **original** sign color; opt-in decision communicated to judges before the attempt.
- [ ] Review any official updates, Q&A, head judge interpretations and organizer-specific logistics.
